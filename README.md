# Node.js & Express.js Server – Practical Implementation 

This repository contains a simple HTTP server using Node.js and an Express.js application. These implementations demonstrate basic server functionality using both core Node.js and Express.js.
## 2021 ict 14 (IT2234)

## 🌟 Prerequisites 🛠️

- Node.js installed on your system
- npm (Node Package Manager) installed

## 📌 Installation

1.Download This repo and Extract Zip Files (in seprete if U prefer)

2. Navigate to the project directory:
   ```sh
   cd <project_directory>
   ```
3. Install dependencies:
   ```sh
   npm install
   ```

## 🚀 How to Run

### ▶ Running the Node.js HTTP Server
1. Run the server using Node.js:
   ```sh
   node server.js
   ```
2. Open your browser and go to:
   ```
   http://127.0.0.1:3000
   ```

### ▶ Running the Express.js Application
1. Navigate to the `myapp` directory:
   ```sh
   cd myapp
   ```
2. Run the Express server:
   ```sh
   node myapp.js
   ```
3. Open your browser and visit:
   ```
   http://127.0.0.1:3002/
   ```
   ```
   http://127.0.0.1:3002/msg
   ```
